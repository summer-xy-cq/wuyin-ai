# PRD: 《黄帝内经》五音 AI 协同诊疗平台 (Competition Special)

## 1. 产品愿景
通过 AI 视觉分析与生成式音频算法，建立中医「辨证-论治-验证」的全流程数字化平台，为亚健康群体提供可私有部署的五音调理方案。

## 2. 核心价值主张 (对标比赛)
- **医学性**: 严格遵循《黄帝内经》五音对应五脏理论。
- **AI 深度**: 实现从图像到参数化实时生成的端到端 AI 链条。
- **科研闭环**: 内置长达14天的临床干预实验，提供真实的疗效反馈数据。

## 3. 详细需求清单

### R1: AI 调师能力 (AI Composer)
- **输入**: 五行偏颇权重 (Wood, Fire, Earth, Metal, Water)。
- **输出**: 包含 Scale(调式), Tuning(频率), BPM(节奏) 的音乐处方。

### R2: 实时音频合成 (Real-time Synthesis)
- **模式 A (共振调理)**: 精准频率输出 (432Hz 及其谐波)。
- **模式 B (旋律干预)**: 算法随机生成的五声音阶古筝伴奏。

### R3: 移动端适配与科研打卡
- 适配 iOS/Android 浏览器的全屏体验。
- 引导用户完成 14 天的 PSQI 量表对比，生成效能验证柱状图。

## 4. 部署方案
- **平台**: Cloudflare Pages.
- **后端接口**: 使用 Cloudflare Functions (Edge Computing), 确保国内访问低延迟。
- **模型**: 国内主流多模态模型 (OpenAI API 兼容)。
